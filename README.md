# Gran Parque Central 3D

Guía interactiva **no oficial** del anteproyecto «Concurso de ideas Plan Maestro Definitivo del Gran Parque Central»
(Guerra de Rossa · Tribuna Sur · Varesi Arquitectos, junio de 2025).

- `index.html`: el sitio completo (el modelo 3D usa three.js desde un CDN).
- `img/`: imágenes tomadas del anteproyecto.

El modelo 3D es un esquema de volúmenes armado a partir de las plantas y cortes del documento.
